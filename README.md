# Circular Matching Game

A drag-and-drop matching game with circular layout.

## Running in GitHub Codespaces

### Quick Start (Python)
```bash
python3 -m http.server 8000
```
Then open the browser when prompted, or go to the PORTS tab and click the globe icon for port 8000.

### Using Live Server Extension
1. Install the "Live Server" extension in Codespaces
2. Right-click on `index.html`
3. Select "Open with Live Server"

### Using Node.js
```bash
npx serve .
```

## Accessing the Game

After starting the server, navigate to:
- `http://localhost:8000/index.html` (Python)
- Or click the URL shown in the PORTS tab

## Development

The game is a single HTML file with embedded CSS and JavaScript. All changes take effect on page refresh.
